# B2World Website

B2World is a responsive IT company website created using HTML, CSS and JavaScript.

## Pages

- Home
- About
- Services
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive Design
- Mobile Navigation
- Dark / Light Mode
- Project Filtering
- Project Details Modal
- Contact Form Validation
- Animated Counters
- Back to Top Button
